# M4 切片：月度 Token 配额 429

> 状态：已批准  
> 日期：2026-08-04  
> 顺序：用量埋点已合 main；本切片完成后 → 仪表盘 / 运营前端

## 1. 目标

- 租户 `quota.monthly_tokens` 超限时，`POST /chat/completions` 与 `POST /search` 返回 **429**
- 错误码 `quota_exceeded`，`details` 含 `used` / `limit` / `reset_at`
- 响应头 `Retry-After`（距下月重置的秒数）

## 2. 已确认决策

| 项 | 选择 |
| --- | --- |
| 维度 | 仅 `monthly_tokens` |
| 挂载 | chat 补全 + search |
| 读数 | hourlies（空则 fallback `llm_usages`）+ Redis 缓存 5 分钟；`limit≤0` 不限额 |
| 响应 | 新 `QuotaExceeded`，非复用 `RateLimited` |
| 架构 | 方案 1：`QuotaService` + FastAPI `Depends` |

## 3. 非目标

- 单用户 QPS / 租户并发问答限流
- `max_documents` / 上传日限额
- ingestion embed 入队拦截
- 前端额度提示页
- 改 `tenants.quota` schema（沿用 jsonb）

## 5. 算法

```
limit = tenant.quota.monthly_tokens  # int，缺省或 ≤0 → allow
month_key = yyyy-mm in timezone (default Asia/Shanghai)
cache_key = irp:quota:{tenant_id}:{month_key}
if cache hit: used = cached.used
else:
  window = [local month start, next month start) as UTC
  used = sum tokens from llm_usage_hourlies in window
       or fallback sum from llm_usages
  SET cache TTL 300
if used >= limit: raise QuotaExceeded(used, limit, reset_at)
```

`reset_at` = 下月 1 日 00:00（租户时区）的 aware datetime。  
`Retry-After` = `max(0, int((reset_at - now).total_seconds()))`。

## 6. 错误响应

```json
{
  "error": {
    "code": "quota_exceeded",
    "message": "本月 Token 额度已用完",
    "details": {
      "used": 50000000,
      "limit": 50000000,
      "reset_at": "2026-09-01T00:00:00+08:00"
    },
    "request_id": "..."
  }
}
```

Header: `Retry-After: <seconds>`

## 7. 测试要点

- 写入超限 hourlies/usages + 小 `monthly_tokens` → chat/search 429 + header
- `monthly_tokens` 缺失或 0 → 不拦截
- Redis 缓存存在时第二次检查不重算 DB（可 mock）
