# industry-rag-platform 设计文档

面向多行业的工业知识库平台（RAG）。本目录是全部设计文档的入口。

## 一页纸概览

| 维度 | 结论 |
| --- | --- |
| 产品定位 | 多租户工业知识库，租户可按行业定制解析、分块与问答策略 |
| 首期范围 | 文档上传解析 → 向量检索 → 带引用溯源的问答 + 基础权限 |
| 部署形态 | 公有云，可自由调用商业大模型 API |
| 后端 | Python 3.11 + FastAPI + SQLAlchemy 2.0(async) + Celery |
| 存储 | PostgreSQL 16 + pgvector（向量与业务数据同库）+ S3 兼容对象存储 |
| 前端 | React 18 + TypeScript + Vite + TanStack Query + Tailwind + shadcn/ui |
| 架构风格 | 模块化单体（Modular Monolith），保留拆分为服务的接缝 |
| 目标规模 | 文档 < 10 万页、并发用户 < 50，单机可承载 |
